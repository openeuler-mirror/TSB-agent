# Virtrust 日志系统

## 概述

Virtrust 项目提供了完整的日志系统，基于 spdlog 实现，支持多种日志级别、文件轮转和自定义日志处理。日志系统采用单例模式，提供线程安全的日志输出。

## 日志级别

日志级别从低到高定义如下：

```cpp
enum class LogLevel {
    TRACE = 0,    // 跟踪信息
    DEBUG = 1,    // 调试信息
    INFO = 2,     // 一般信息
    WARN = 3,     // 警告信息
    ERROR = 4,    // 错误信息
    CRITICAL = 5, // 严重错误
    UNKNOWN       // 未知级别
};
```

## 核心 API 接口

### Logger 类

#### 1. 获取单例实例

```cpp
static Logger *Instance();
```

#### 2. 初始化日志系统

```cpp
VirtrustRc InitLog(int logLevel = static_cast<int>(LogLevel::INFO), 
                   const char *path = nullptr,
                   int rotationFileSize = DEFAULT_ROTATION_FILE_SIZE,
                   int rotationFileCount = DEFAULT_ROTATION_FILE_COUNT);
```

**参数说明：**
- `logLevel`: 日志级别，默认为 INFO
- `path`: 日志文件路径，nullptr 表示输出到标准输出
- `rotationFileSize`: 单个日志文件大小，默认 20MB，范围 [1MB, 500MB]
- `rotationFileCount`: 日志文件保存数量，默认 20，范围 [1, 64]

**返回值：**
- `VirtrustRc::OK`: 初始化成功
- `VirtrustRc::ERROR`: 初始化失败

#### 3. 设置自定义日志函数

```cpp
bool SetCustomLogFunction(const std::function<CustomLogFunTy> &func);
```

**函数签名：**
```cpp
using CustomLogFunTy = void(LogLevel level, std::string_view msg);
```

**注意：** 不能使用带捕获的 lambda 表达式

#### 4. 设置显示日志级别

```cpp
void SetDisplayLogLevel(LogLevel level);
LogLevel GetDisplayLogLevel();
```

#### 5. 日志输出接口

```cpp
void Log(LogLevel level, std::string_view msg);
void Reset();
```

## 便捷宏定义

### 标准日志宏

```cpp
VIRTRUST_LOG_TRACE(...);  // 跟踪级别
VIRTRUST_LOG_DEBUG(...);  // 调试级别
VIRTRUST_LOG_INFO(...);   // 信息级别
VIRTRUST_LOG_WARN(...);   // 警告级别
VIRTRUST_LOG_ERROR(...);  // 错误级别
```

### 断言宏

```cpp
VIRTRUST_ASSERT_LOG_RETURN(condition, return_value);
VIRTRUST_ASSERT_LOG_RETURN_VOID(condition);
```

## 使用示例

### 1. 基本使用

```cpp
#include "virtrust/base/logger.h"

// 初始化日志系统
auto ret = Logger::Instance()->InitLog(
    static_cast<int>(LogLevel::INFO), 
    "/var/log/virtrust.log"
);
if (ret != VirtrustRc::OK) {
    // 处理初始化失败
    return;
}

// 使用便捷宏记录日志
VIRTRUST_LOG_INFO("Application started successfully");
VIRTRUST_LOG_DEBUG("Debug information: {}", debug_data);
VIRTRUST_LOG_WARN("Warning: configuration file not found");
VIRTRUST_LOG_ERROR("Failed to connect to database: {}", error_msg);
```

### 2. 自定义日志处理

```cpp
#include "virtrust/base/logger.h"

// 设置自定义日志函数
bool success = Logger::Instance()->SetCustomLogFunction(
    [](LogLevel level, std::string_view msg) {
        // 自定义日志处理逻辑
        std::string prefix = LogLevelToStr(level);
        fmt::print("[CUSTOM {}] {}\n", prefix, msg);
        
        // 可选：发送到远程日志服务
        // SendToRemoteLogService(level, msg);
    }
);

if (success) {
    VIRTRUST_LOG_INFO("Custom log function set successfully");
}
```

### 3. 动态调整日志级别

```cpp
#include "virtrust/base/logger.h"

// 运行时调整日志级别
Logger::Instance()->SetDisplayLogLevel(LogLevel::DEBUG);

// 获取当前日志级别
auto currentLevel = Logger::Instance()->GetDisplayLogLevel();

// 重置为默认设置
Logger::Instance()->Reset();
```

### 4. 文件轮转配置

```cpp
#include "virtrust/base/logger.h"

// 配置文件轮转：每个文件 10MB，最多保留 5 个文件
auto ret = Logger::Instance()->InitLog(
    static_cast<int>(LogLevel::DEBUG),
    "/var/log/virtrust/app.log",
    10 * 1024 * 1024,  // 10MB
    5                  // 保留 5 个文件
);

// 配置输出到标准输出
auto ret = Logger::Instance()->InitLog(
    static_cast<int>(LogLevel::INFO),
    nullptr  // nullptr 表示输出到 stdout
);
```

### 5. 条件日志记录

```cpp
#include "virtrust/base/logger.h"

void ProcessData(const std::string& data) {
    // 使用断言宏进行条件检查
    VIRTRUST_ASSERT_LOG_RETURN(!data.empty(), );
    
    VIRTRUST_LOG_DEBUG("Processing data of size: {}", data.length());
    
    if (data.length() > 1024) {
        VIRTRUST_LOG_WARN("Large data size detected: {} bytes", data.length());
    }
    
    // 处理逻辑...
    VIRTRUST_LOG_INFO("Data processing completed");
}
```

## 日志输出格式

### 默认格式
```
[VIRTRUST filename:line] message
```

### 自定义函数格式示例
```cpp
Logger::Instance()->SetCustomLogFunction(
    [](LogLevel level, std::string_view msg) {
        auto now = std::chrono::system_clock::now();
        fmt::print("[{} {:%Y-%m-%d %H:%M:%S}] {}\n", 
                   LogLevelToStr(level), now, msg);
    }
);
```

## 注意事项

1. **线程安全**: Logger 类是线程安全的，可在多线程环境中使用
2. **性能考虑**: 日志级别低于当前显示级别的日志不会被处理
3. **文件路径**: 初始化时指定的日志文件路径必须存在
4. **自定义函数**: 不能使用带捕获的 lambda 作为自定义日志函数
5. **内存管理**: Logger 采用单例模式，无需手动释放资源

## 错误处理

### 初始化失败处理
```cpp
auto ret = Logger::Instance()->InitLog(static_cast<int>(LogLevel::INFO), log_path);
if (ret != VirtrustRc::OK) {
    // 使用标准输出记录错误
    fmt::print(stderr, "Failed to initialize logging system\n");
    return -1;
}
```

### 自定义函数设置失败处理
```cpp
bool success = Logger::Instance()->SetCustomLogFunction(customFunc);
if (!success) {
    VIRTRUST_LOG_ERROR("Failed to set custom log function");
}
```
